Vulnerability Report: Cross-Site Scripting (XSS) in User Profile

Report ID: #2024-001 | Submitted by: Alex Turner

Description

A cross-site scripting (XSS) vulnerability was discovered in the user profile section of the application. This allows attackers to inject malicious scripts into user profiles, potentially leading to data theft or other security breaches.

Steps to Reproduce

  1. Log in to the application with a valid user account.
  2. Navigate to the user profile settings.
  3. In the "About Me" section, enter the following script: <script>alert('XSS')</script>
  4. Save the profile changes.
  5. View the profile to trigger the script.
